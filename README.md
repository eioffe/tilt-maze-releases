# Tilt Maze — Android downloads

A wooden-labyrinth game split across two phones: one player steers pitch, the other
roll. This repo holds the latest installable build only; the source is private.

**[⬇ Download page](https://eioffe.github.io/tilt-maze-releases/)** — open it on the phone.

Android 12 or newer. Both phones need the same build. Updates install over the top
and keep the app's data.

Sideloaded, not on the Play Store: the first install asks you to allow installs from
Chrome or Files, and Play Protect may note an unrecognised developer, which it says
about any app from outside the store. No account, no analytics, no internet use; the
phones talk to each other directly over Nearby Connections.

The build lives on the `gh-pages` branch, replaced on each deploy.
